# Stock Data Ingestion and Analysis

This project aims to ingest historical stock data from the Charles Schwab API, store it in a database, and perform analysis on the data.

## Features

- Ingest historical stock data from the Charles Schwab API
- Store stock data in a database
- Re-use minute data to construct different interval data
- Enable web socket for live data ingestion
- Detect abnormal moves across different tickers
- Use indicators and candle patterns to detect bullish/bearish moves
